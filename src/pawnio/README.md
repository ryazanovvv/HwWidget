# PawnIO module

`AMDFamily17.bin` is a compiled module for the [PawnIO](https://github.com/namazso/PawnIO) driver. It reads the
temperature of AMD Zen CPUs, and `../hwwidget.rc` builds it into HwWidget.exe as a resource.

- **Source:** `AMDFamily17.p` from [PawnIO.Modules](https://github.com/namazso/PawnIO.Modules), release 0.2.11.
- **License:** Copyright (C) 2025 namazso, GNU Lesser General Public License 2.1 or later; see `COPYING`.
- **Where the binary came from:** the resources of
  [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor), which ships the same module.
  It may come from a slightly different release than the source here. Every release, with its source, is on the
  [PawnIO.Modules releases](https://github.com/namazso/PawnIO.Modules/releases) page.
